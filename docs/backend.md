# growa — Backend (Cloud Functions + Storage)

## รันในเครื่อง

ต้องมี Node 22+, Java 21 และ Firebase CLI

```bash
npm install
cd functions && npm install && cd ..
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm test` | รันเทสต์ทั้งหมด: ชุดคำถามอาการ, Firestore rules, Storage rules และ Cloud Functions แบบต้นจนจบ |
| `npm run test:rules` | รันเฉพาะเทสต์ rules |
| `npm run emulators` | เปิด emulator ไว้พัฒนาต่อ (Ctrl+C เพื่อหยุด) |
| `npm run seed` | ใส่ข้อมูลลง emulator ที่เปิดอยู่: ร้านยามีใบอนุญาตจาก อย. 3,260 ร้าน, ฐานข้อมูลยา, ร้านพาร์ทเนอร์จำลอง 2 ร้าน และบัญชีทดสอบ 4 บัญชี |
| `npm run import:fda` | สร้าง [data/pharmacy-directory-bangkok.json](../data/pharmacy-directory-bangkok.json) ใหม่จากไฟล์ของ อย. |
| `npm run smoke:live` | ทดสอบกับ Google Places และ Claude จริง (ต้องมี key) |

บัญชีทดสอบจาก `npm run seed` มีอยู่ใน emulator เท่านั้น รหัสผ่านอยู่ใน [scripts/seed.mjs](../scripts/seed.mjs)

| อีเมล | บทบาท |
|---|---|
| `mom@demo.test` | ผู้ป่วย มียาความดันที่ใกล้หมด |
| `daughter@demo.test` | ผู้ดูแลของคุณแม่ (ดูยา บันทึกการกินยา สั่งเติมยาได้) |
| `pharmacist@demo.test` | เภสัชกรของร้านจำลอง demoRx1 (ยืนยันใบอนุญาตแล้ว) |
| `admin@demo.test` | ผู้ดูแลแพลตฟอร์ม |

> สคริปต์ทั้งหมดใส่วิธีแก้ปัญหา emulator บน Windows ("Unable to establish loopback connection") ไว้แล้ว
>
> ข้อความ `secretmanager ... 403` ใน log ของ emulator เป็นเรื่องปกติเมื่อยังไม่ใส่ key ไม่กระทบการทำงาน

## ชุดคำถามประเมินอาการ (ไม่ใช้ AI)

ไฟล์ [functions/src/symptom-tree.js](../functions/src/symptom-tree.js) ถามทีละข้อ และแต่ละคำตอบจะตัดทางเลือกให้แคบลงจนได้ผลลัพธ์

1. **คัดสัญญาณอันตรายก่อนเสมอ** (ถามเป็น checklist) ถ้าพบ จะแนะนำให้โทร 1669 หรือ 1323 ทันที
2. **ข้อมูลผู้ป่วย:** อายุ, เพศ, ตั้งครรภ์หรือให้นมบุตร, โรคประจำตัว
3. **ระบบร่างกาย → อาการหลัก → คำถามเจาะจง** จนได้ผลลัพธ์ ครอบคลุม 8 ระบบ ได้แก่ ไข้/หวัด/ไอ/เจ็บคอ, ศีรษะ, ทางเดินอาหาร, ผิวหนัง/แผล, กล้ามเนื้อ/ข้อ, ตา/หู/ปาก/ฟัน, ปัสสาวะ/สุขภาพสตรี, นอนไม่หลับ
4. **ผลลัพธ์:** มี 75 แบบ แต่ละแบบบอกว่า "อาการเข้าได้กับ…" (ไม่ใช่การวินิจฉัย) พร้อมระดับการดูแล 5 ระดับ ได้แก่ ดูแลตัวเอง → ปรึกษาเภสัชกร → พบแพทย์ → พบแพทย์ภายในวันนี้ → ฉุกเฉิน รวมถึงคำแนะนำ และสัญญาณที่ควรรีบไปหาหมอ
5. **ยกระดับการดูแลอัตโนมัติ:**
   - ทารกต่ำกว่า 3 เดือน: อย่างน้อย "พบแพทย์ภายในวันนี้"
   - ต่ำกว่า 1 ปี: อย่างน้อย "พบแพทย์"
   - เด็ก 1–5 ปี, ผู้สูงอายุ, ตั้งครรภ์/ให้นมบุตร, มีโรคประจำตัว: อย่างน้อย "ปรึกษาเภสัชกร"

ทุกเส้นทางคำตอบที่เป็นไปได้ถูกเทสต์อัตโนมัติใน [tests/symptom-tree.test.js](../tests/symptom-tree.test.js) ว่าจบที่ผลลัพธ์เสมอ และไม่มีคำถามหรือผลลัพธ์ที่ไปไม่ถึง

ฝั่งแอปเรียก `guidedTriageStart` → `guidedTriageAnswer` (ส่งคำตอบทีละข้อ) → `guidedTriageBack` (ย้อนกลับ) เมื่อได้ผลแล้ว `triageShareWithPharmacy` จะส่งคำถามและคำตอบทั้งหมดให้เภสัชกร

> เนื้อหาชุดนี้เป็นฉบับเริ่มต้นสำหรับ Hackathon ต้องให้เภสัชกรและแพทย์ตรวจทานก่อนใช้จริง

## ข้อมูลร้านยา

| แหล่ง | ใช้เมื่อ | ได้อะไร |
|---|---|---|
| **อย. ข้อมูลเปิด** (ใบอนุญาตสถานที่ขายยา ปี 2024) + **OpenStreetMap** | ค่าเริ่มต้น และเมื่อไม่มี Google key | ร้านยาที่มีใบอนุญาต ขย.1 จริงในกรุงเทพฯ 3,260 ร้าน: ชื่อ, เลขใบอนุญาต, **เวลาปฏิบัติการของเภสัชกร**, แขวง/เขต |
| Google Places | เมื่อใส่ `GOOGLE_MAPS_API_KEY` | ที่อยู่และพิกัดจริง, เวลาเปิด, เบอร์โทร, คะแนน และรีวิวสูงสุด 5 รายการ (ดึงสด ห้ามเก็บ) |

ข้อจำกัดของข้อมูล อย.:
- **ตำแหน่งเป็นค่าโดยประมาณ:** ข้อมูลไม่มีที่อยู่หรือพิกัด จึงใช้จุดกึ่งกลางของแขวง (3,182 ร้าน) หรือของเขต (78 ร้าน) แอปต้องแสดงเป็น "อยู่ในแขวง…" ไม่ใช่หมุดตรงร้าน
- **ไม่มีรีวิว:** รีวิวใช้ระบบของ growa เอง (`pharmacyRatings`) ซึ่งรีวิวได้เฉพาะคนที่สั่งซื้อและได้รับของจริง
- **ข้อมูลอัปเดตล่าสุด ส.ค. 2024**

ตอนร้านสมัคร (`registerPharmacy`) ระบบจะเทียบเลขใบอนุญาตกับข้อมูล อย. ให้อัตโนมัติ (`licenseFoundInFdaData`) โดยไม่สนการเว้นวรรคหรือจุด ช่วยให้ admin ตรวจร้านง่ายขึ้น

สินค้า ราคา สต็อก และประเภทยายังเป็นข้อมูลจำลองใน [scripts/seed-data.mjs](../scripts/seed-data.mjs) เพราะไม่มีแหล่งข้อมูลเปิด

## API keys (ถ้ามีในอนาคต)

| Secret | ใช้ใน |
|---|---|
| `GOOGLE_MAPS_API_KEY` | `searchPharmacies` จะเปลี่ยนไปใช้ Google และเปิดใช้ `getPharmacyPlaceDetails` |
| `GEMINI_API_KEY` | แชต AI ด้วย Gemini ฟรี (`triageSendMessage`) ซึ่งเป็นทางเลือกเพิ่มจากชุดคำถาม |

- **ใช้ใน emulator:** ใส่ใน `functions/.secret.local`
- **ใช้บน production:** `firebase functions:secrets:set <NAME>`

## แชต AI (ทางเลือก ต้องมี key): ชั้นความปลอดภัย

1. **กฎตายตัวตรวจทุกข้อความก่อนเรียก AI** (`RED_FLAGS` ใน [functions/src/triage.js](../functions/src/triage.js))
2. **Claude (`claude-opus-5-5`) ตอบเป็น JSON ตาม schema** ห้ามวินิจฉัย และห้ามแนะนำยาหรือขนาดยา
3. **เซิร์ฟเวอร์เป็นคนตัดสิน route สุดท้าย:** สัญญาณอันตรายชนะเสมอ, คุยเกิน 12 ข้อความจะส่งต่อเภสัชกร, AI ตอบไม่ได้ก็ให้ปรึกษาเภสัชกร
4. **อนุมัติยาได้เฉพาะเภสัชกรที่ยืนยันใบอนุญาตแล้ว** ผลอนุมัติใช้ได้ 24 ชั่วโมง และเฉพาะยาที่ระบุไว้
