มาสคอตและไอคอน

แคปซูลยิ้มประจำแอป ใช้ในคำทักทาย หน้าว่าง และตอนสำเร็จ เพื่อให้แอปดูเป็นเพื่อนที่คอยดูแล ไม่ใช่ระบบแพทย์ที่น่ากลัว ไม่ใช้ในหน้าฉุกเฉิน

ไอคอนเส้นหนา 2px ปลายมน ชุดเดียวทั้งแอป ไม่ใช้อีโมจิ

หลักการที่ใช้ทุกหน้า

  • 1หนึ่งหน้าจอ หนึ่งเรื่องหลัก มีปุ่มหลักเพียงปุ่มเดียวที่เด่นที่สุด
  • 2ตัวอักษรเริ่มต้น 18px มีโหมดตัวใหญ่ ปุ่มสูงอย่างน้อย 48px
  • 3มุมโค้งใหญ่ 24px พื้นครีมนุ่ม เงาอุ่น ไม่ใช้ไล่สีหรืออีโมจิ
  • 4บอกความปลอดภัยให้เห็นเสมอ: "เภสัชกรเป็นผู้อนุมัติ AI ไม่จ่ายยา" และติดป้าย "ข้อมูลจำลอง" ทุกจุดที่ไม่ใช่ข้อมูลจริง
  • 5มือถือก่อน แล้วขยายเป็นแถบด้านข้างบนจอใหญ่ (ดูแผนผังหน้า)
