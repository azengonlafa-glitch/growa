# growa — วิธีเปิดเดโมและสคริปต์นำเสนอ

## เปิดเดโม

ต้องมี Node 22+, Java 21 และ Firebase CLI (`npm install -g firebase-tools`) ติดตั้งครั้งแรกด้วย:

```bash
npm install
npm --prefix functions install
npm --prefix web install
```

จากนั้นเปิดเดโม:

```bash
npm run demo
```

คำสั่งนี้จะเปิด emulator → ใส่ข้อมูลเดโม → เปิดเว็บที่ **http://localhost:5180** (กด Ctrl+C เพื่อปิดทั้งหมด)

ทุกครั้งที่เปิดใหม่ ข้อมูลจะเริ่มจากศูนย์ แต่ละขั้นจึงทดลองซ้ำได้ ถ้าเล่นไปแล้วอยากรีเซ็ตกลางทาง ให้รัน `npm run seed` ในอีกหน้าต่าง (จะรีเซ็ตยาของคุณแม่ ร้าน และข้อมูลเดโม แต่คำสั่งซื้อที่สร้างไปแล้วยังอยู่)

## บทบาทในหน้าล็อกอิน

| ปุ่ม | ใช้เดโมอะไร |
|---|---|
| **คุณแม่** | ผู้ป่วยความดันและเบาหวาน มียา 3 ตัว แอมโลดิปีนใกล้หมด |
| **ลูกสาว** | ผู้ดูแลของคุณแม่ (ดูยา บันทึกการกินยา สั่งเติมยาแทนได้) |
| **เภสัชกร** | ร้านพาร์ทเนอร์ demoRx1 ยืนยันใบอนุญาตแล้ว |

> เคล็ดลับ: เปิดสองหน้าต่าง (หนึ่งในนั้นเป็น incognito) แล้วล็อกอินคนละบทบาท จะเห็นสถานะอัปเดตแบบเรียลไทม์ทั้งสองฝั่ง

## เส้นทางหลัก (ทีละขั้น)

หลังล็อกอิน แอปพาไปทีละหน้า ไม่ต้องหาเมนู:

1. **เลือกร้าน:** แผนที่สแกนร้านพาร์ทเนอร์ในรัศมี 50 กม. (ใช้ตำแหน่งของฉัน หรือ "ตำแหน่งตัวอย่าง อนุสาวรีย์ชัยฯ") แตะร้านแล้วกด "เลือกร้านนี้"
2. **เลือกประเภท:** "สั่งสินค้าประเภทยา" หรือ "ของทั่วไปในร้านยา" ถ้าเลือก "ของทั่วไป" จะเป็นหน้าร้านแบบแอปช้อปปิ้ง: ค้นหา หมวด (ผมและผิว วิตามิน อาหารเสริม ช่องปาก อุปกรณ์สุขภาพ) เรียงราคา ใส่ตะกร้า แล้ว "ไปชำระ" (ไม่ต้องตอบคำถามอาการ ไม่ผ่านเภสัชกร แต่ร้านยังต้องยืนยันสต็อกก่อนชำระ)
3. **ตอบคำถามอาการ** แล้วได้ผล 3 แบบ:
   - **ยาทั่วไป** (หวัด เจ็บคอไวรัส ปวดหัวตึงเครียด ท้องเสียทั่วไป แมลงกัด): แนะนำยาที่ร้านมี เลือกแล้วสั่งได้เลย
   - **ต้องคุยเภสัชกร** (เช่น เจ็บคอจากแบคทีเรีย): แชต/โทรหาร้านที่เลือก เภสัชกรถามต่อ ตอบ แล้วอนุมัติรายการยา → สั่งได้
   - **ควรพบแพทย์ / ฉุกเฉิน:** ไม่เปิดให้สั่งยา ฉุกเฉินแสดง 1669 (สุขภาพจิต 1323)
4. **ตรวจรายการ + เลือกช่องทางชำระ** แล้วกดยืนยัน ระบบยังไม่เก็บเงิน ร้านตรวจสต็อก (และเภสัชกรประเมินถ้าจำเป็น) ก่อนจึงจะชำระได้ (กฎข้อ 2)

ฟีเจอร์เดิม (ยาของฉัน ครอบครัว โปรไฟล์สุขภาพ แจ้งเตือน คำสั่งซื้อ) อยู่หลังปุ่มรูปคนมุมขวาบน "โฮมแคร์และเมนู" ชั่วคราว

### ปุ่ม "จำลองร้านตอบ" (เฉพาะเดโม)

หน้า "คุยกับเภสัชกร" มีปุ่มนี้เมื่อร้านเป็นร้านตัวอย่าง: กดครั้งแรกเภสัชกรจำลองถามกลับ ตอบแล้วกดอีกครั้งจะอนุมัติรายการยา
เปิดใช้เฉพาะใน emulator หรือเมื่อตั้ง `DEMO_SIMULATION=true` (ฝั่ง API) และ `VITE_DEMO_SIMULATION=true` (ฝั่งเว็บ) ใช้ได้กับคำขอของตัวเองที่ร้าน `sample: true` เท่านั้น
ผลที่ได้บันทึกเป็น `pharmacistUid: "demo-simulator"` และ audit `demo.review.simulate` จึงแยกจากการอนุมัติของเภสัชกรจริงได้เสมอ
ถ้าไม่ใช้ปุ่มนี้ ให้ล็อกอินเป็น "เภสัชกร" อีกหน้าต่างแล้วตอบที่ "คิวประเมิน" ตามปกติ

### ติดตามคำสั่งซื้อและปุ่มจำลองร้าน (เฉพาะเดโม)

หลังกด "ยืนยันสั่งซื้อ" จะเข้าหน้า `#/track/<orderId>` ที่แสดงขั้น: ร้านยืนยันสต็อก → ชำระเงิน (จำลอง) → ร้านจัดยา → กำลังจัดส่ง → ได้รับยา
ปุ่ม "จำลองร้านยืนยันสต็อก / จัดยาเสร็จ / ส่งของ" เรียก `demoPharmacyOrder` (กติกาเดียวกับปุ่มจำลองร้านตอบ: เฉพาะ emulator หรือ `DEMO_SIMULATION=true`, ออเดอร์ของตัวเอง, ร้าน `sample: true`, audit `demo.order.simulate`)
การชำระเงินและ "ฉันได้รับยาแล้ว" ยังเป็นของผู้ซื้อเอง และยาที่ต้องผ่านเภสัชกรจะไม่ถูกยืนยันจนกว่าจะมีผลอนุมัติแนบมา
แผนที่จัดส่งเป็นเส้นตรงจากร้านถึงบ้าน คนส่งและเวลาถึงเป็นข้อมูลจำลอง (วิ่งครบเส้นทางใน 1 นาทีบนหน้าจอ)

## สคริปต์เดโมเดิม (ระบบดูแลยาและครอบครัว)


1. **ปัญหา (คุณแม่ → หน้าแรก):** ยาวันนี้ "ยังไม่ได้บันทึก" และแอมโลดิปีน "เหลือประมาณ 5 วัน" แจ้งเตือนขึ้นที่กระดิ่ง
2. **ครอบครัว (ลูกสาว):** หน้าแรกเห็นยาของคุณแม่ → หน้า "ยาของฉัน" สลับเป็นคุณแม่ → กด "✓ กินแล้ว" แทน → กด "ขอเติมยา" แอมโลดิปีน → เลือกร้าน → ส่งคำขอ
3. **ด่านเภสัชกร (เภสัชกร → ร้านของฉัน):**
   - "คำสั่งซื้อใหม่" กด "มีสินค้า ยืนยัน"
   - "คิวประเมิน" แสดงอายุ ประวัติแพ้ยา (penicillin) และยาที่ใช้อยู่ → กด "อนุมัติ"
   - จุดที่ควรเน้น: **ระบบยังไม่เก็บเงินจนถึงขั้นนี้**
4. **ชำระและจัดส่ง:**
   - ลูกสาวกด "ชำระ" (จำลอง) หรือลอง "จำลองชำระไม่สำเร็จ" ก่อน
   - เภสัชกรกด "เริ่มจัดเตรียมยา" → "ส่งให้ผู้จัดส่ง"
   - ลูกสาวกด "ยืนยันว่าได้รับยาแล้ว" → จำนวนยาคงเหลือของคุณแม่เพิ่มขึ้นเอง → รีวิวร้านได้
5. **ประเมินอาการ (ผู้ใช้คนใดก็ได้):**
   - ตอบทีละข้อ เช่น "ไม่มีอาการเหล่านี้" → 18–64 → … → เจ็บคอ → ได้ผล "ควรปรึกษาเภสัชกร"
   - กด "ส่งให้เภสัชกร" → เภสัชกรอนุมัติยาในคิว → ผู้ใช้กดไปสั่งยาได้โดยไม่ต้องประเมินซ้ำ
   - ลองเลือก "เจ็บแน่นหน้าอก" ในข้อแรก → ระบบหยุดทันทีและขึ้นปุ่มโทร 1669
6. **ผู้ใช้ใหม่:** สมัครสมาชิก → ระบบพาไปหน้าโปรไฟล์สุขภาพ → กรอกปีเกิด ประวัติแพ้ยา และโรคประจำตัว ปิดความยินยอมได้ ถ้าปิด เภสัชกรจะเห็นป้าย "ควรถามก่อนจ่ายยา" แทนข้อมูล
7. **ร้านยาใกล้ฉัน:** ร้านที่มีใบอนุญาตจริงจาก อย. 3,260 ร้าน พร้อมเวลาปฏิบัติการของเภสัชกร ส่วนร้านพาร์ทเนอร์ (ข้อมูลจำลอง) สั่งซื้อได้

## บอกกรรมการตรง ๆ ว่าอะไรจริง อะไรจำลอง

| จริง | จำลอง |
|---|---|
| รายชื่อร้านยาที่มีใบอนุญาตจาก อย. (ตำแหน่งโดยประมาณระดับแขวง) | ร้านพาร์ทเนอร์ สินค้า ราคา สต็อก |
| ระบบสิทธิ์และความปลอดภัย (Security Rules ผ่านเทสต์ 49 รายการ) | การชำระเงินและการจัดส่ง |
| ลำดับขั้นตอนสั่งซื้อ / เภสัชกร / เติมยา ที่บังคับฝั่งเซิร์ฟเวอร์ | รีวิวตัวอย่าง 3 รายการ |
| ชุดคำถามประเมินอาการ (ยังต้องให้ผู้เชี่ยวชาญตรวจทาน) | บัญชีผู้ใช้เดโม |
